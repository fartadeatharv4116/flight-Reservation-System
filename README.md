## Features
- Tkinter GUI to view demo flights.
- Linear Search by Flight ID, airline, source, or destination.
- Binary Search by exact Flight ID.
- Bubble Sort by ticket price (ascending and descending).
- Reserve a selected demo flight and view bookings during the current run.
- Displays search comparisons and sort comparison/swap counts.

## Requirements
- Python 3.x
- Tkinter (included with most standard Python installations)

## Run
```bash
python main.py
```

## Important note
This is an educational demonstration. Flight data is sample data; bookings are stored only in memory while the application is running. It does not connect to an airline, accept payments, or issue real tickets.
