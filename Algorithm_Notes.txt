1. Linear Search
Input: list of flights, search query
1. Convert query to lowercase.
2. Set result list empty and count = 0.
3. For each flight: count += 1; compare query against ID, airline, source and destination.
4. If any field matches, append flight to result list.
5. Return result list and count.
Time: O(n) average/worst. Space: O(k) for k matches.

2. Binary Search by Flight ID
Input: list of flights, exact ID
1. Sort a copy by Flight ID.
2. Set low = 0 and high = n - 1.
3. While low <= high: mid = (low + high) // 2; count += 1.
4. If middle ID equals target, return it.
5. If middle ID is less than target, low = mid + 1; otherwise high = mid - 1.
6. If loop ends, report not found.
Search time after sorting: O(log n); preparation sort: O(n log n); copy space O(n).

3. Bubble Sort by Ticket Price
Input: list of flights and sort direction
1. Copy the list.
2. For each pass, compare adjacent prices.
3. Swap when the pair is in the wrong order.
4. If no swaps occur in a pass, stop early.
5. Return sorted list, comparisons, swaps.
Best time O(n), average/worst O(n^2), copied-list space O(n).
